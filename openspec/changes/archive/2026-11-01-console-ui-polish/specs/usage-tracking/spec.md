# Spec Delta

## ADDED Requirements

### Requirement: 长内容可通过悬浮完整查看

系统 SHALL 在使用页面的日志表与统计表中，为内容可能超出列宽的单元格（如"厂商/模型"组合名）提供悬浮查看完整内容的能力。

#### Scenario: 日志表厂商/模型列悬浮查看
- **WHEN** 使用页面日志表中某行的"厂商/模型"内容超出列宽
- **AND** 管理员将鼠标悬浮于该单元格
- **THEN** 系统以气泡形式显示完整的厂商与模型名

#### Scenario: 统计卡片模型列悬浮查看
- **WHEN** "厂商模型统计"卡片中某行的模型名超出列宽
- **AND** 管理员将鼠标悬浮于该单元格
- **THEN** 系统以气泡形式显示完整的模型名
